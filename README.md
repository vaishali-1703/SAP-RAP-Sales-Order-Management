 SAP RAP Sales Order Management

 Project Overview
This project is a Sales Order Management application developed using the **SAP RESTful Application Programming Model (RAP)** and ABAP Cloud.

It manages customers, sales order headers, and sales order items through a Fiori Elements interface.

 Technologies Used
- SAP ABAP Cloud
- RESTful Application Programming Model (RAP)
- Core Data Services (CDS)
- Behavior Definitions and Behavior Implementations
- Eclipse ADT
- SAP Fiori Elements
- OData Services

 Main Features

 1. Customer Management
- Create customers
- View customer details
- Update customer information
- Delete customer records
- Draft functionality

2. Sales Order Management
- Create and manage sales orders
- Update and delete sales orders
- Manage order status
- Draft functionality

 3. Sales Order Item Management
- Create and manage sales order items
- Update item details
- Delete items
- Automatic item amount calculation

 Project Structure
- Customer Management
- Sales Order Header
- Sales Order Item
- CDS Views
- Behavior Definitions
- Metadata Extensions
- Service Definitions and Bindings

Development Environment
Developed using Eclipse with ABAP Development Tools (ADT) on an SAP ABAP Cloud practice system.

 Author
Developed as an SAP ABAP Cloud and RAP learning project.
